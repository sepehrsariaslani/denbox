# Denbox for Mac

Denbox is a native SwiftUI movie and series library for macOS. It keeps the catalog, My List, and personal title ratings in SQLite, uses the API route patterns found in the supplied Simba APK for search and title details, and presents film and series pages with metadata, seasons, episodes, and selectable playback sources.

The interface defaults to Persian, with English selectable in Settings and right-to-left layout for Persian. Navigation, catalog search, discovery, watch history, personal ratings, downloads, charts, settings, genres, IMDb roles, public-title import, offline actions, and the embedded player's controls and common errors have Persian translations; some detail messages and raw provider/player errors still fall back to English. Original movie, series, person, and provider names remain unchanged.

Denbox bundles the Peyda font family for its Persian and English interface.

The built-in player runs libmpv in its own resizable window and supports seeking, playback speed, video/audio/subtitle track selection, selectable macOS audio output devices, external audio and primary/secondary subtitle files, audio and subtitle delay, saved subtitle size/position/font settings, aspect ratio and crop, rotation, chapter navigation, A–B repeat, a local playlist with reorder/shuffle, hardware decoding and deinterlacing controls, picture adjustments, a ten-band audio equalizer, frame capture with or without subtitles, and IINA-style keyboard shortcuts. Network playback uses a 45-second mpv cache with automatic pause/rebuffering and keeps the last rendered frame visible between video updates; full-screen window changes reconnect libmpv to the active OpenGL context. It resumes from saved progress and records viewing activity locally. When a series episode ends, the player offers the next playable episode without closing the player. The build bundles libmpv and its runtime libraries from the installed IINA app; playback itself runs inside Denbox.

## API and data

- TVmaze cast cards can show a portrait and character name when that profile data is available. Selecting a cast member opens the local IMDb People page, using the matched IMDb person ID when available and falling back to an exact name match. The imported IMDb dataset provides the local filmography.

- The Mac client uses the APK route shapes `first/{key}`, `search/{query}/{key}`, `movie/by/{id}/{key}`, and `season/by/serie/{id}/{key}`. It uses the current HTTPS origin advertised by the APK config endpoint (`ninwinios.info/api`), then falls back to the known HTTPS service host. Catalog feeds remain on their configured HTTPS endpoints. The current cache remains available in `~/Library/Application Support/Simba/library.sqlite` so upgrading the app name does not discard the existing catalog.
- Opened movie and series detail responses are stored in that same SQLite database. Reopening a title displays its saved details immediately, including when the Mac is offline; entries older than five minutes refresh in the background and update the page when fresh API data arrives.
- Denbox does not call Frappe routes. API keys stay in macOS Keychain under the existing Simba service identity; they are not stored in this repository or app bundle.
- The media API can return plain HTTP streams and redirect them across hosts. For this personal build, ATS allows arbitrary media and network loads so the player can follow those HTTP redirects. API routes in Denbox still use HTTPS. This broad setting lowers transport security for network connections made by the app.
- Movie and series feeds are paginated in batches of 30. Use **Load more titles** in the Movies or TV Shows sections to continue through the feed. Pages are cached in the existing SQLite library, so titles loaded earlier remain available after restarting Denbox.
- The shared search field matches loaded titles, subtitles, and alternate names. It shows an in-progress state while remote catalog search runs, and searches started from discovery pages show the resulting catalog matches. My Ratings search stays local.
- Selecting a title opens a full detail page in the main window, with navigation back to the catalog. Direct video links from movie details and individual episode details can be downloaded to `~/Downloads/Denbox`. Completed downloads are linked to their catalog title and episode in SQLite, so reopening a detail page shows an offline badge and a **Play Offline** action; missing files are not shown as available. When the source honors HTTP byte ranges, Denbox downloads up to eight parts concurrently, reports bytes as they arrive, and verifies the assembled size; sources that reject or ignore ranges fall back to a normal download. HLS (`.m3u8`) and DASH (`.mpd`) playlists are not converted by this downloader.
- Detail-page Play and Download actions refresh API links when the cached details have no usable source; **Download this season** refreshes the series page, queues each episode with a direct-file link, and reports episodes that lack a direct download. Clicking an episode title in **Continue Watching** opens its series details, selects that episode, and scrolls to its row. Resume refreshes remote links before playback and prefers an already saved offline episode.
- **Download / refresh IMDb data** in Settings fetches IMDb's official public datasets over HTTPS. Denbox imports title metadata, ratings, episode numbering, person names, principal cast credits, and director/writer credits into `~/Library/Application Support/Denbox/imdb-metadata.sqlite`. The IMDb People page searches the local name index and shows paginated movie and TV filmographies; selecting a credit searches the Simba catalog and opens its details. The compressed source files are temporary and deleted after import. The IMDb Charts page builds local top-rated and most-voted lists from ratings and votes. Its Top 250 style ranking uses the published weighted formula with a report-wide mean calculated separately for movies and TV series, plus the 25,000-vote minimum. IMDb does not publish which voters count as regular voters, and the downloadable data does not include their vote totals, so Denbox cannot reproduce the official chart exactly. Trending embeds IMDb's live Most Popular Movies and TV Shows charts, and Box Office embeds the live worldwide lifetime-gross chart from Box Office Mojo. IMDb's official bulk files contain no photos, biographies, plot text, or franchise membership. Title posters are matched through the configured Simba catalog and cached in `~/Library/Application Support/Simba/library.sqlite`; IMDb Franchises shows curated franchise collections as local IMDb title cards; selecting a card searches the local Simba catalog. Series matching prioritizes exact titles and uses release year to rank duplicate or fuzzy matches. Episodes match by title first and fall back to season/episode numbering such as `S01E01`, then display IMDb rating and vote count where available. Similar titles are a local genre-overlap ranking, not IMDb's official recommendations. Descriptions still come from the configured media API. The IMDb dataset is for personal, non-commercial use; it is not bundled with releases. Attribution: “Information courtesy of IMDb (https://www.imdb.com). Used with permission.”

- Metadata source priority is field-specific: IMDb supplies its own title IDs, ratings/vote counts, genres, episode ratings, and ordered principal credits; TVmaze supplements series artwork, summary/rating, character names, cast portraits, and IMDb person IDs when available; Wikidata fills missing facts and can contribute a Persian description. TVmaze is used for series, not as a replacement for IMDb ratings or film credits. If reference providers return both Persian and English summaries, Denbox keeps the Persian one. The detail page prefers Persian text from Filimo, HexDL, the Simba catalog, or public references before using an English fallback. IMDb's bulk people data has no photos, so portrait images come from TVmaze and remain attached to their source citation. Series cached before cast portraits were added are automatically rechecked once.
- When a movie or series detail page opens, Denbox automatically searches Filimo and HexDL public title pages, follows only an exact title/year match, then saves visible Persian text, synopsis, poster, episode snippets, and source URL in the existing SQLite database. Successful results refresh after 30 days; unsuccessful lookups are held for 24 hours to avoid repeated searches. The search uses non-persistent WebKit without a site login. It does not read player, stream, or download URLs; playback and download sources remain the configured Simba routes. A public page URL can also be entered manually when automatic matching misses.
- Public reference metadata from Wikidata, TVmaze, and optional TMDB refreshes automatically for movie/series titles whose detail page is opened. The **Check public references for loaded titles** Settings action can also retry eligible titles in the loaded catalog. Requests are limited to three titles at a time. Wikidata uses a matched IMDb title ID when available, with a strict title/year/type search fallback, to fill description, release year, runtime, genres, country, director, cast, and artwork; TVmaze adds series cast, cast portraits, character names, poster, summary, and rating. When configured, TMDB can add original titles, taglines, content ratings, networks, writers, keywords, trailers, and backdrops. Saving or replacing its token forces a fresh TMDB lookup for loaded titles. Tokens stay in macOS Keychain. Metadata lookups send title search terms or matched IMDb IDs; viewing history and My List are not sent. Results are cached locally and link to their source on the detail page. The IMDb dataset remains the primary source for IMDb ratings, genres, episode ratings, and ordered credits. TVmaze requires visible attribution and publishes its API data under CC BY-SA. TMDB attribution is shown in Settings. Metadata coverage varies by title.
- Startup and long lists render lazily: the cached catalog appears before background IMDb matching finishes, home shelves and episode/history rows instantiate only as they become visible, and IMDb catalog matches are saved in one SQLite transaction. Similar-series rows use a partial covering index and a genre-set cache; completed offline files are indexed by catalog/episode identity and normalized title instead of rescanning every download for each episode row.

- Viewing activity stays in the Denbox SQLite database on this Mac. **Continue Watching**, **Watch History**, and **Viewing Stats** use saved playback sessions; the built-in libmpv player saves position and watched time and can resume. **Export JSON** in Viewing Stats includes local viewing progress, sessions, personal title ratings, and title snapshots. For videos opened directly from this Mac, the export can also include their full file paths; save the JSON somewhere you trust. **Import JSON** previews the file and merges it into this Mac: newer local progress and ratings win, duplicate history sessions are skipped, and existing data is not deleted. Imports accept schema versions 1 and 2 and files up to 50 MB. Clearing viewing history leaves personal ratings intact. Episode progress can match by season/episode label if the media API changes its episode IDs. Genre filters and preferences use the local IMDb genres. **For You** combines local viewing history, chosen genres, and your personal star ratings to rank IMDb candidates; titles already watched or rated are omitted. Recommendations need the IMDb datasets to be imported, and a candidate only becomes playable when it matches a title in the configured media catalog. The large IMDb candidate list is indexed and loaded only when **For You** is opened; repeated requests use an in-memory cache. Genre counts are loaded when **Genres** is opened. Use **Movies** or **TV Shows** to filter the loaded local catalog.

- Completed downloads store their catalog and episode IDs in SQLite. Reopening the title shows an offline indicator and a **Play Offline** action; Denbox checks that the file still exists before offering it.
- Rate each movie or series from its detail page with one to five stars. These personal ratings are stored only in the local SQLite library, separate from IMDb ratings, and appear in **My Ratings**. Denbox saves a title snapshot with each rating so it stays in that list after a catalog refresh removes the title.

## Build

```sh
mkdir -p dist/Denbox.app/Contents/{MacOS,Resources,Frameworks}
mkdir -p dist/Denbox.app/Contents/Resources/fa.lproj
mkdir -p dist/Denbox.app/Contents/Resources/Fonts
cp Resources/Info.plist dist/Denbox.app/Contents/Info.plist
cp Resources/AppIcon.icns dist/Denbox.app/Contents/Resources/AppIcon.icns
cp Resources/Denbox-Icon.png dist/Denbox.app/Contents/Resources/Denbox-Icon.png
cp Resources/TMDB-Logo.png dist/Denbox.app/Contents/Resources/TMDB-Logo.png
cp Resources/Fonts/*.ttf dist/Denbox.app/Contents/Resources/Fonts/
cp Resources/fa.lproj/Localizable.strings dist/Denbox.app/Contents/Resources/fa.lproj/Localizable.strings
cp /Applications/IINA.app/Contents/Frameworks/*.dylib dist/Denbox.app/Contents/Frameworks/
swiftc -parse-as-library -swift-version 5 -O \
  -target arm64-apple-macosx13.0 \
  -I Sources/MPV -framework SwiftUI -framework AppKit -framework OpenGL -framework Network \
  -framework Security -framework UniformTypeIdentifiers -framework WebKit -lsqlite3 \
  -Xlinker -rpath -Xlinker @executable_path/../Frameworks \
  Sources/SimbaMac.swift Sources/DenboxLanguage.swift Sources/MPVPlayback.swift Sources/IINAPlaybackMonitor.swift Sources/PublicTitleMetadata.swift Sources/PublicMetadataDiscovery.swift Sources/PublicTitlePageImportView.swift Sources/ReferenceMetadata.swift \
  Sources/SegmentedDownloader.swift Sources/IMDbMetadata.swift Sources/ViewingActivity.swift \
  /Applications/IINA.app/Contents/Frameworks/libmpv.1.dylib \
  -o dist/Denbox.app/Contents/MacOS/Denbox
codesign --force --deep --sign - dist/Denbox.app
```

The build links and bundles libmpv and its runtime libraries from the installed IINA app, then runs that engine inside Denbox. IINA must be installed to build this personal bundle; playback does not launch the IINA app. The bundle identifier and existing Keychain/database locations intentionally retain the Simba identity so this rename keeps the current API credentials, catalog cache, and My List. This build targets Apple Silicon and macOS 13 or newer. It is ad-hoc signed and not notarized.

The current embedded video surface uses AppKit OpenGL APIs, which the macOS SDK marks deprecated; the app still builds, but the renderer should be revisited for long-term macOS support.

## Verification

`Tests/IMDbChartRankingTests.swift` verifies the 25,000-vote boundary for movie and series Top 250-style lists, separate report-wide means, weighted ordering, miniseries inclusion, and deterministic vote-count tie-breaking using a local SQLite fixture.

`Tests/WatchRecommendationHistoryTests.swift` verifies that watched IMDb titles stay out of **For You** even when their progress records are older than the 2,000 most recent rows, while unfinished titles remain eligible.

`Tests/DenboxSourceParserTests.swift` checks movie and series source parsing, including the API's `downloadas` flag. `Tests/CatalogPersistencePerformanceTests.swift` verifies fast, durable 1,000-row catalog and batched IMDb metadata writes. `Tests/DownloadLookupPerformanceTests.swift` measures indexed offline lookups across hundreds of downloads and checks title fallback and missing-file handling. `Tests/OfflineDownloadPersistenceTests.swift` checks that completed media remains discoverable after reopening SQLite, tolerates regenerated episode IDs, and ignores missing files. `Tests/PersonalRatingPersistenceTests.swift` checks creating, updating, reloading, validating, and clearing local personal ratings. `Tests/StartupResponsivenessTests.swift` checks that saved titles appear immediately and recommendation indexing stays lazy. `Tests/IMDbGenreIndexPerformanceTests.swift` checks genre and covering-index migration, recommendation ordering/ranking, and in-memory caches; with `--database PATH` it measures an installed IMDb database. `Tests/APIRoutePerformanceTests.swift` verifies that a fast usable API route wins over a slow route and empty responses are skipped. `Tests/PlaybackRoutingTests.swift` checks that Denbox initializes embedded libmpv, updates core playback controls, and does not launch IINA. `Tests/PublicTitleMetadataTests.swift` checks Filimo/HexDL URL allowlists, strict title matching, Persian synopsis selection/preservation, and local JSON persistence. `Tests/ReferenceMetadataTests.swift` checks TMDB, TVmaze, and Wikidata parsing, strict title/year matching, token-gated refresh behavior, merge behavior, both SQLite metadata caches across reopen, lookup cooldown persistence, and attribution. `Tests/IINAPlaybackMonitorTests.swift` checks the separate Unix-socket monitor implementation; the current embedded player reports progress directly and does not use that monitor. `Tests/SegmentedDownloaderTests.swift` uses a local synthetic HTTP server to verify concurrent range assembly/checksum and the no-range fallback. `Tests/DenboxLiveAPITests.swift --catalog-only` verifies the live movie/series feeds and details; `--mpv-probe-only` opens live movie and episode links with their API headers through libmpv; the full run also checks arbitrary HTTP byte ranges and pagination. Tests print counts and sanitized error codes only, never API keys or media URLs.
